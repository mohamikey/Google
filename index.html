06 — Roadmap

Where this goes after the hackathon

The prototype is the first phase of a rollout built for real kitchens, not a one-off demo.

01
Phase 1 — Pilot

Local kitchen pilot

Run the forecasting pipeline against one real kitchen's historical sales for 4–6 weeks, comparing recommended prep against actual waste to validate the model in the field.

02
Phase 2 — Integration

Direct POS API integrations

Replace manual CSV uploads with live connections to common POS platforms, so forecasts refresh automatically as sales come in rather than on a manual export cycle.

03
Phase 3 — Accreditation

Sustainability accreditation

Package verified waste-reduction data into reporting kitchens can use toward sustainability certifications and share with their own customers.
